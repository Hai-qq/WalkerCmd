# WalkerCmd：双足速度指令跟踪的 RL 与"虚实差距"鲁棒性评测

目标：在 MuJoCo 里复现运控 RL 的最小闭环——**速度指令跟踪 → 域随机化（DR）→ 留出扰动评测**，
并用多随机种子和统计检验回答"域随机化到底带来了什么"。环境是 Gymnasium 的 Walker2d-v5（2D 双足），
**没有真机、没有 IsaacLab/IsaacSim/MjLab，也没有真实的 sim2real 迁移**；这里的"虚实差距"用仿真里的参数偏移、噪声、延迟和外推力来代理。

## 做了什么
- `walkercmd/env.py`：每个 episode 采样前进速度指令 v_cmd∈[0.5, 2.0]，观测 = 17 维状态 + v_cmd；
  奖励 = 存活 + 2·exp(-(v-v_cmd)²/0.25) - 1e-3·‖a‖²。
  扰动：摩擦、质量（含转动惯量）、关节驱动增益、观测噪声、动作延迟、躯干外推力。
- `walkercmd/ppo.py` / `train.py`：从零写的 PPO（高斯策略、观测与回报归一化、GAE、时间截断自举），3M 步 / 次。
- `walkercmd/evaluate.py`：逐因素扫描评测，含**训练 DR 范围之外**的水平；确定性策略；3 个指令速度 × 8 个 episode。
- `walkercmd/summarize.py`：按种子聚合（均值±标准差）+ 精确置换检验（5 vs 5 个种子）+ 鲁棒性曲线。
- `tests/`：6 个测试（参数不累积漂移、指令进观测、推力施加与清除、延迟缓冲、固定种子可复现、评测确定性）。

两种训练配置各 5 个种子：**无 DR** vs **DR**（摩擦 0.4–1.6、质量 0.7–1.3、增益 0.7–1.3、观测噪声 0–0.02、延迟 0–2 步、推力 0–150 N）。

## 结果（存活率 = 1000 步内不倒；* 表示 p≤0.05）
完整表：`results/summary.md`；曲线：`results/robustness.png`；原始数据：`results/eval.csv`。

|---|---|---|---|---|
| nominal | – | 0.97±0.04 | 0.98±0.04 | 1.000 |
| mass | 0.6（范围外） | 0.53±0.21 | 0.91±0.15 | 0.024* |
| mass | 1.4（范围外） | 0.54±0.44 | 0.83±0.28 | 0.222 |
| gear | 0.6（范围外） | 0.21±0.25 | 0.68±0.45 | 0.095 |

### 结论（只写数据支持的）
1. **标称条件下 DR 没有代价**：存活率 0.97 vs 0.98，速度 RMSE 0.33 vs 0.36（无显著差异）。
2. **动作延迟上 DR 的收益最大且显著**：无 DR 的策略在 1 步延迟时存活率降到 0.25，2 步时全部摔倒；DR 策略分别是 0.98 / 0.87，3 步（训练范围外）仍有 0.48。
3. **质量偏轻（0.6）显著受益**；质量偏重、驱动增益偏弱、外推力上**方向一致地更好，但 5 个种子下不显著**（p=0.10–0.28），不能当作确证。
4. **观测噪声**、**摩擦 ≤1.0**：两者无差别。
5. **失败点（两者都有）**：摩擦 1.5（在 DR 训练范围内）存活率仅 0.43 / 0.65，种子间方差很大；外推力 ≥200 N 时两者都大面积摔倒。说明 DR 范围内并不等于范围内都稳。

## 局限（面试时请如实说）
- 2D Walker2d，不是 3D 人形；没有关节力矩限制、接触模型的真实差距，也没有真机。**不能据此声称 sim2real 能力。**
- 种子数 5，每个条件 24 个 episode；置换检验未做多重比较校正。
- 随机化范围是我手工选的，没有做范围消融；也没有对比 AMP / 模仿学习 / 自适应（如 RMA）等方法。
- 速度指令只覆盖 0.5–2.0 的直线前进，没有转向、地形和全身运动跟踪。

## 复现
```bash
uv venv .venv --python 3.12
uv pip install --python .venv/bin/python torch numpy "gymnasium[mujoco]" mujoco matplotlib pytest pandas
PYTHONPATH=. .venv/bin/python -m pytest -q tests
./run_all.sh                      # 10 个训练并行，约 10 分钟（M 系列 CPU）
PYTHONPATH=. .venv/bin/python -m walkercmd.evaluate --runs runs --out results/eval.csv
PYTHONPATH=. .venv/bin/python -m walkercmd.summarize results/eval.csv results
```
